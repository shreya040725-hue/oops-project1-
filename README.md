# 🔐 Password Security System

A C++ based OOPS mini project that analyzes password strength and generates secure random passwords.

## Features
- Password strength analysis.
- Checks uppercase, lowercase, digits and special characters.
- Detects commonly used passwords.
- Displays security score and strength (Weak, Moderate, Strong).
- Generates random passwords of 8–64 characters.
- Handles invalid inputs.

## Technologies Used
- C++
- MinGW GCC Compiler
- Visual Studio Code
- STL Libraries

## OOPS Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Runtime Polymorphism
- Function Overriding

## How to Run

Compile:
```bash
g++ -std=c++14 1.cpp -o password.exe
```

Execute:
```bash
.\password.exe
```
